# Student Analyzer System 

## Description
Student Analyzer is a simple Python-based student management program. It allows the user to add student details, view student information, and calculate the student's result based on their marks.
This project is created using basic Python concepts such as functions, lists, dictionaries, loops, conditional statements, and user input. 

## Features
1.Add student details
2.Store student name, roll number, and marks
3.View student details
4.Calculate student grades
5.Display result as Grade A, B, C, or Fail
6.Menu-driven program
7.Exit the program safely

## Technologies used
1.Python
2.Lists
3.Dictionaries
4.Functions
5.if-elif-else
6.loops

## Grading System Used
85 and above == Grade "A"
between 75 and 84 == Grade "B"
between 50 and 74 == Grade "C"
below 50 == "Fail"

## How it works
1. Add Student
2. View Student 
3. Calculate Result 
4. Exit
As you run Programm they will show an 4 choices above shown you have to first Add Student,
then you can view student , calculate student's Result and then Exit.
1.When you chose 2.view Student they will show students Name , Roll No and Marks .
2.When you chose 3.Calculate Result they will give you an Grade achived by Student accordingly.
3.And When you chose 4.Exit they will simply exit the System.
